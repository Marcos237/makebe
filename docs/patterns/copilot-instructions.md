# 🎨 UI + Vitrine Instructions

## 🎯 Objetivo
Gerar interfaces modernas para sistema de agendamento de cabeleireiro com foco em conversão.

---

## 🧠 Conceito Visual

A interface deve transmitir:

- sofisticação
- tecnologia
- confiança
- experiência premium

Inspirado em:
- SaaS modernos
- dark UI
- glassmorphism leve

---

## 🌑 HERO

- fundo escuro com imagem
- radial gradient suave
- alto contraste

Estrutura:
- título forte
- subtítulo curto
- botão CTA

Texto padrão:
"Transforme seu visual com profissionais especializados"

Botão:
"Agendar agora"

---

## ✂️ SERVIÇOS

- cards com glass effect
- bordas arredondadas
- hover com elevação

Cada item:
- ícone
- título
- descrição

Layout:
- 4 colunas desktop
- 1 coluna mobile

---

## ⭐ PROFISSIONAIS

- cards com foto
- fundo escuro
- sombra leve

Cada item:
- foto
- nome
- especialidade

---

## 📅 CTA

Texto:
"Pronto para renovar seu visual?"

Botão:
"Agendar horário"

---

## 🎨 ESTILO GLOBAL

Usar:
- tema escuro
- gradientes
- sombras suaves
- bordas arredondadas

Evitar:
- fundo branco
- cores fora do padrão
- layout pesado

---

## 🎨 CORES (OBRIGATÓRIO)

Usar variables.css:

- var(--bg-gradient)
- var(--primary)
- var(--success)
- var(--danger)
- var(--text-primary)

---

## 🧩 COMPONENTES

Sempre criar:

- Header
- HeroBanner
- ServicesSection
- ProfessionalsSection
- CTASection
- Footer

---

## 📱 Responsividade

- mobile first
- botões full width

---

## ⚠️ REGRAS

- não inventar cores
- não mudar identidade visual
- focar em conversão (agendar)
